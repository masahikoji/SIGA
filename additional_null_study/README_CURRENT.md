# Earlier heterogeneous-effect null studies

These files are an archival supplement to the new paired pilot, not results
from the covariance reconstruction. `r3_results/null_summary_final.csv` is
the supplied full-precision moderate-setting summary. The strong-setting
`stress_summary_reconstructed.csv` is explicitly a reconstruction from earlier
displayed aggregates. It is NOT the original execution output. Keep that name
and provenance; reconcile it with the original strong-run `r3_null_summary.csv`
and execution configuration before using it as independently reproducible data.

The nested source has been expanded under `source/`; `sign_exact/` contains
finite-state verification programs. Archived source READMEs describe the
earlier version and do not override the current manuscript's conditions.
The current primary pilot uses estimated effects, not model-known effects.
No new full R simulation was executed during this integration.
