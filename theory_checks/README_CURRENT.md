# Previously supplied theoretical computation files

The `verification/` and `assignment_simulation/` directories are preserved
from the author's earlier revision package. They include exact finite-inequality
checks, block covariance checks, numerical probability enclosures and independent
allocation-direction calculations. They were not all rerun in the current pilot
integration. Their original seeds, output records and comments are retained.

These programs verify particular algebraic or numerical claims; they are not a
machine-checked proof of all results in the manuscript. Directory names inherited
from earlier versions are computational identifiers, not new statistical terms.
