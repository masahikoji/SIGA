# Assignment-only check of selected covariance directions

Run `sh run_all.sh` from this directory. A C++17 compiler and Python with NumPy
and SciPy are needed. OpenMP is optional: the serial and parallel generators
produce the same raw product sums for a given seed. Set `CXX` to the compiler
name if necessary. The optional `verify_new_results.py` test additionally uses
`g++` with OpenMP; the main reproduction does not require that test.

For each of two five-factor minimisation settings, 200,000 independent triples
select a direction and 100,000 new independent triples evaluate it. A third
setting is an independent-assignment control. The factor probabilities are
(.50,.40,.30,.20,.10), in the bit order recorded in the JSON. The original
absolute-range rule with overall balance and equal weights is implemented in
C++. This is a new implementation of the same probability law, not execution
of the archived R source or reuse of its random seeds.

The main program `run_new.sh` records all six master seeds. Each repetition has
separate profile and three assignment RNG streams. The assignment streams share
only the profile sequence. `analyze_split.py` uses the averaged centred training
covariances and retains dependence between the two product vectors within each
triple in the evaluation standard error. The evaluation uses squared projections
and their exactly zero population means. Its confidence interval concerns the
finite-trial-size variance ratio along the selected direction, conditional on
selection; it is not a confidence interval for a population smallest eigenvalue
or the limiting minimum.

No outcomes, test-rejection indicators, or selected trial sample sizes are
simulated. The original operating-characteristic tables are unchanged.

The run creates six raw .bin files (about 115 MB altogether). These are little-
endian int16 arrays with dimensions [repetition, 2, 32], containing unnormalised
product sums. They are regenerated by the supplied code and omitted from this
compact archive. Their SHA-256 hashes are in split_results.json. The selected
directions, full training and evaluation covariance matrices, results, standard
errors and control are included. Do not interpret the stored minimum from the
selection sample as an independently evaluated variance ratio.
